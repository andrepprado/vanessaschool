# English in Your Time – English Learning Platform

A complete English learning platform developed for **Teacher Vanessa Ghiringhelli**, focused on structured language learning, interactive lessons, student progression, personalized review, achievements and learning management.

This platform transforms the English learning journey into a practical digital experience, combining structured content, interactive exercises, progress tracking, XP, study streaks, audio resources and student management in a responsive web application.

---

## 🖥 Live Version

🔗 https://vanessaschool.vercel.app/

---

## 📌 About This Project

This project was designed as a **complete digital platform for English learning**, covering:

- Student authentication and controlled access
- Structured English learning paths
- CEFR-based proficiency levels
- Interactive lessons and exercises
- Automatic lesson progression
- Student progress tracking
- XP and study streak system
- Personalized review based on previous errors
- Achievement system
- Audio and pronunciation support
- Student profile management
- Administrative student management
- Responsive learning experience

It follows a lightweight technical structure:

- Pure **HTML**, **CSS**, and **JavaScript**
- No front-end frameworks
- Modular JavaScript architecture
- Clean and organized code
- Fully responsive
- Dynamic lesson and exercise logic
- **Supabase** integration
- Local persistence
- Service Worker support
- Vercel deployment

## 🧩 Features

### ✔️ **Structured Learning Journey**
Students follow an organized learning path instead of accessing isolated exercises without progression.

### ✔️ **CEFR-Based Content**
The platform organizes English content through internationally recognized proficiency levels.

### ✔️ **Interactive Exercises**
Lessons include interactive activities with automatic validation and immediate feedback.

### ✔️ **Progress Tracking**
Student progress is stored and displayed throughout the learning experience.

### ✔️ **Lesson Progression**
Lessons follow a structured progression, guiding students through the appropriate learning sequence.

### ✔️ **Personalized Review**
Incorrect answers can become review points, allowing students to revisit areas where additional practice is needed.

### ✔️ **XP & Gamification**
Experience points provide measurable progress and additional motivation during the learning journey.

### ✔️ **Study Streaks**
The platform tracks study consistency and encourages students to maintain regular contact with English.

### ✔️ **Achievements**
A dedicated achievement system creates additional milestones throughout the learning process.

### ✔️ **Audio Learning**
Pronunciation and audio resources complement text-based exercises and support listening practice.

### ✔️ **Student Dashboard**
The main student area consolidates level, progress, XP, streak, completed lessons, achievements and the next learning activity.

### ✔️ **Student Management**
Administrative tools allow authorized users to register, view and edit student information.

### ✔️ **Role Separation**
Student and administrative environments use separate access flows according to their purpose.

### ✔️ **Responsive Layout**
The interface adapts to desktop, tablet and mobile resolutions.

### ✔️ **Persistent Learning Data**
Student progress and account-related information can be maintained between sessions.

### ✔️ **Feedback System**
Lessons provide visual and audio feedback during interactive learning activities.

### ✔️ **Consistent Visual Language**
The platform uses organized cards, clear visual hierarchy, readable content and an interface focused on the learning experience.

## 🛠 Technologies Used

- **HTML5** – semantic structure and learning content organization
- **CSS3** – responsive layout, visual hierarchy, cards and interface styling
- **JavaScript (ES6+)** – lesson engine, exercises, progression and dynamic interface logic
- **Supabase** – authentication, student data and platform persistence
- **PostgreSQL** – relational data storage
- **LocalStorage** – browser-side persistence for local information
- **Service Worker** – resource and audio caching support
- **Web Audio / Speech Resources** – pronunciation and learning audio functionality
- **Vercel** – deployment and hosting
